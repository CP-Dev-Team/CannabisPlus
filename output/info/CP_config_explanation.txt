CannabisPlus creates configs in the "profiles/CannabisPlus/" folder.
The main config is "CannabisPlus.json" and each strain has its own JSON in "CannabisStrains/".
Fertilization reduces the growtime and doubles the crop.
Growtime adds a randomizer so the time is not 100% exact.

Folder structure:
    profiles/CannabisPlus/CannabisPlus.json              // Main config
    profiles/CannabisPlus/CannabisStrains/Skunk.json     // Per-strain configs
    profiles/CannabisPlus/CannabisStrains/BlueGod.json
    profiles/CannabisPlus/CannabisStrains/PurpleKush.json
    profiles/CannabisPlus/CannabisStrains/Stardawg.json
    profiles/CannabisPlus/CannabisStrains/Future.json
    profiles/CannabisPlus/CannabisStrains/S1.json
    profiles/CannabisPlus/CannabisStrains/Nomad.json
    profiles/CannabisPlus/CannabisStrains/BlackFrost.json

=== Explanation of CannabisPlus.json (Main Config) ===

    "ConfigVersion": 312,                               // Mod version the config was saved with.  312 = 3.1.2.  Don't change; the mod uses it to update your config.
    "EnableServerDebugLogging": false,                   // Enables debug logging on the server.
    "EnableClientDebugLogging": false,                   // Enables debug logging on the client.
    "ActivateJointSmokingEffect": 1,                     // 1 = Activates effects when smoking joints; 0 = No effect.
    "SmokingJointEffectSeconds": 360,                   // Duration the effect will last, in seconds.
    "JointCyclesToActivateEffect": 10,                   // How many cycles to activate the effect.  20 = One joint.
    "SecondsToDryCannabisPlant": 30,                      // Time in seconds for raw cannabis plants to dry on the drying post.
    "CP_WorkbenchSettings": {                            // Nested workbench settings (older configs called this "WorkbenchSettings"; it's renamed automatically):
        "RequireBattery": 1,                             //   1 = Require a car or truck battery attached to the workbench; 0 = No battery needed.
        "PowerUsed": 1,                                  //   Energy used per bag or brick, in units of 15 energy.  1 = 15 energy (1% of a full truck battery, 3% of a car battery).  Ignored if RequireBattery = 0.
        "PlasticWrapUsage": 10,                          //   Plastic wrap used per brick.
        "ProcessingSeconds": 5                           //   Time in seconds to process each bag or brick.
    }

=== Explanation of Strain JSONs (Per-Strain Config) ===

Each strain has its own JSON file in the CannabisStrains folder.
All strains share the same settings structure.  You can customize each strain independently.
Delete the CannabisStrains folder to regenerate all defaults.

    "MinutesToGrow": 8,                                       // Growtime of this strain in minutes.
    "CropCount": 2,                                      // Amount of crop to harvest from this strain.
    "SeedsPerPackage": 9,                                // Amount of seeds in a seedpack for this strain.
    "WeedEffects": {                                     // Per-strain visual effects when smoking:
        "HueIntensity": 58.0,                            //   Manipulating the hue.  Probably shouldn't change.
        "RadBlurXPower": 2,                              //   Radial blur for the x-axis (0-100).
        "RadBlurYPower": 2,                              //   Radial blur for the y-axis (0-100).
        "RotBlurPow": 10                                 //   Rotation blur power (0-100).
    }

=== Notes ===

Mod updates keep your settings.  New settings are added with their default values, settings that no longer exist are removed,
and a copy of your old files is saved in "profiles/CannabisPlus/ConfigBackup/v<old version>/".
If a file has a mistake in it (for example a missing comma), the script log shows an error and that file uses default settings until it's fixed.

Settings that were previously in CannabisPlus.json but have been moved:
    - Per-strain growtime, cropcount, and seed count are now in each strain's own JSON.
    - Per-strain weed effects are now in each strain's own JSON.
    - "removeAfterHarvest" and "spoiltime" are now in AgricultureCore's config.
    - Vanilla plant settings (pepper, tomato, etc.) are now in GardeningPlus's config.
