v4 (in development - branch v4, not released yet)
New: Strain genetics (part 1 of the breeding update)
- Strains are no longer separate items. Every strain now uses one set of items (buds, bags, bricks, joints,
  joint packs, seeds, seed packs, plants, raw plants), and each item remembers its strain. Item names and
  textures still show the strain, for example "Skunk Bud" with the Skunk look.
- 28 real strains ship with the mod, each bred from its commonly cited real parents:
  - Found-only (loot and traders): Afghani, Thai, Hindu Kush, Acapulco Gold, Colombian Gold, Durban Poison, Hawaiian,
    Purple Afghani, Purple Thai, plus Chemdawg, Haze, Purple Skunk, Blackberry and Harlequin (real strains whose
    origin is unknown or disputed).
  - Bred: Northern Lights, OG Kush, Purple Kush, Tres Dawg, God Bud (tier 1); Skunk #1, Blueberry, Girl Scout
    Cookies, Stardawg, Zombie OG (tier 2); Super Skunk, Blue God (tier 3); Jack Herer, Sour Diesel (tier 4).
  Breeding itself comes in a later part of v4.
- Nomad, S1, Black Frost and Future are retired (they aren't real strains). Their items become Afghani, Harlequin,
  Northern Lights and Super Skunk, which also take over their textures.
- Every strain has its own seed pack (CP_CannabisSeedsPack<Strain>, e.g. CP_CannabisSeedsPackJackHerer), so loot and
  traders can offer specific strains. The sample types.xml makes packs rarer the deeper the strain is in the tree.
  CP_CannabisSeedsPackGenetic gives a random found-only strain instead.
- Strains have their own textures (new: Acapulco Gold, Afghani, Blueberry, Girl Scout Cookies, Durban Poison,
  Harlequin, Jack Herer, OG Kush, Sour Diesel, Zombie OG). Strains without textures yet use plain cannabis textures.
  Textures live in CfgCannabisStrainLooks, so another mod can add looks for custom strains.
- Items only stack with items of the same strain. Splitting a stack keeps the strain.
- The strain carries through everything: seed pack -> seeds -> plant -> raw plant -> drying post -> buds ->
  workbench bags and bricks -> ripping open / unwrapping -> joints -> joint packs -> unpacking.
- CBD crude oil can be made from buds of any strain with at least 40 CBD (Harlequin by default) instead of S1 only.
- Custom strain files are full strains now: add a json file and the strain exists, no new item classes needed.

Your players' items are converted, nothing is lost
- Items of the old per-strain classes (CP_CannabisSkunk, CP_CannabisBagBlueGod, CP_JointPack_Nomad, ...) turn into
  the new item of their strain automatically when the server loads or spawns them, in the same place, with the
  same quantity and health.
- Plants already growing in plots keep growing and their harvest is converted. Seeds already sitting in a plot
  grow a plant of their strain.
- Items locked in a running workbench or drying post still count as their strain and are converted on the next
  restart.

Config Changes (REQUIRED)
- types.xml / traders: the 8 sets of per-strain classes are replaced by one set: CP_CannabisGenetic,
  CP_CannabisBagGenetic, CP_CannabisBrickGenetic, CP_JointGenetic, CP_JointPack_Genetic, CP_CannabisSeedsGenetic,
  CP_Plant_CannabisGenetic (and CP_RawGeneticCannabisPlant), plus one seed pack per strain. See the updated
  CP_sample_cannabisplus_types.xml. Remove the old per-strain entries; if you keep them, those items spawn and
  convert into the new ones. The seed packs of Skunk, Blue God, Purple Kush and Stardawg keep their class names,
  so those entries keep working. Trader prices are now per item type, not per strain (except seed packs).
- Strain files of retired strains (Nomad.json, S1.json, BlackFrost.json, Future.json) are no longer used; the
  server log says so. Your file is left in place.
- Strain files (profiles/CannabisPlus/CannabisStrains/*.json) get new settings, added automatically with the
  strain's built-in values: DisplayName, Description, Tier, ParentA, ParentB (a parent written "A+B" is the unnamed
  first cross of A and B), Look (whose textures the strain uses, any strain with textures, "" = plain) and Traits
  (Potency, Yield, Speed, Hardiness, Resin, CBD, Aroma, 0-100). Your MinutesToGrow, CropCount, SeedsPerPackage and
  WeedEffects are kept.
- The new built-in strains get their own files on the first start after updating. A built-in strain file you
  delete stays deleted until the next CannabisPlus update.
- Grow time and buds per plant now come from each plant's strain file.

New: Workbench window
- The workbench now runs on AgricultureCore's bench system (the same one as the DrugsPLUS chemistry bench).
  Requires the AgricultureCore version that includes it; update both mods together.
- Look at the workbench and use "Open bench": pick Fill bags or Wrap bricks, see what's attached, what's missing and
  what you're carrying, then Start. "Load from inventory" moves the bagger/wrapper, battery, buds, empty bags and
  plastic wrap you carry onto the bench in one click.
- Both keep going by themselves while there's enough, like before. Bags keep the strain of their buds and bricks
  the strain of their bags; different strains are never mixed in one bag or brick.
- Buds, empty bags, bags, bricks and plastic wrap now all go into the workbench's storage (10x10) instead of their
  own slots, so you can load several strains at once and the bench works through them one after another. Only the
  bagger, the wrapper and the battery are attachments. New bags and bricks appear in the storage (on the ground when
  it's full). The old 160 bag / 25 brick stop is gone.
- Workbenches from CannabisPlus 3 keep everything: items in the old slots are moved into the storage when the server
  loads (next to the bench if the storage is full).
- Placing the workbench kit now shows the green/red hologram instead of the solid model.
- Removed actions: "Fill bag with ...", "Wrap ...", "Pause/Resume production" and "Stop processing" (all in the
  window now; Stop ends the current batch).

Config Changes
- New settings in CP_WorkbenchSettings: "BudsPerBag" (default 2) and "BagsPerBrick" (default 16). They're added to
  your CannabisPlus.json automatically.

Fixes
- CannabisPlus no longer overrides the vanilla truck battery proxy, which removed the TruckBattery slot from it.

Existing workbenches keep their attached machines, battery and items (tested with a save from the current release).
No items lost: the per-strain item classes are retired and converted automatically (see Strain genetics).
Config changes required: types.xml and trader entries for the new strain items (see Strain genetics).
Requires the AgricultureCore version with the bench framework and strain hooks; update both mods together.

Next update (unreleased)
Mod Changes
- Unpacking joint packs now uses AgricultureCore's shared unpack action. Requires the latest AgricultureCore.
- Unpacking DrugsPLUS and vanilla cigarette packs is now handled by DrugsPLUS instead of CannabisPlus.
- Unpacked joints now drop onto the ground surface instead of at the player's exact position.
- Dried cannabis plants can be put in AgricultureCore's new compost bin.
- The fertilizing-speed settings code moved to AgricultureCore. The settings themselves were already in AgricultureCore.json, so nothing changes for you.

Fixes
- Smoking too much now makes players vomit on multiplayer servers. Before, the server never counted joint puffs, so it only worked in singleplayer.
- The stoned screen effect now reliably starts after JointCyclesToActivateEffect puffs on multiplayer servers. Before, the count could be reset by the server mid-smoke.
- The stoned screen effect now combines with DrugsPLUS effects instead of being cleared when one of them wears off. Needs the latest AgricultureCore.
- Drying post: raw plants with no yield set (for example spawned with admin tools or bought from traders) now dry into the strain's CropCount instead of 1 bud.
- Drying post: no longer creates an extra empty bud when the total divides evenly into stacks.
- Drying post: buds that don't fit in the post now drop on the ground next to it instead of being lost.
- Drying post: players can no longer try to take plants off while it's drying, and the rope can't be pulled off a post that has items on it.
- Crafting names and the "Rip open" action are now translated (they were always English): Fill Bag, Wrap Brick,
  Roll Joint, Create a pack of joints, Put joint into pack, Make Wooden Drying Post, Make CBD Crude Oil,
  Make Cannabis Workbench Kit, Tear apart Workbench.

Config Changes
- Your settings in CannabisPlus.json and your strain files are now kept when the mod updates. Previously an update moved every strain file into ConfigBackup and replaced them with defaults, so custom strains disappeared from the strains folder. New settings are added with their default values and settings that no longer exist are removed. A copy of your old files is still saved in profiles/CannabisPlus/ConfigBackup/v<old version>.
- If CannabisPlus.json or a strain file has a mistake in it (for example a missing comma), the mod now logs an error in the script log and uses default settings for that file until it's fixed, instead of silently using zeros. Your file is not overwritten.

DayZ 1.30 Server Setup (IMPORTANT)
- DayZ 1.30 has a bug (Bohemia ticket DZEXP-134) that stops mods from listing files in the profiles folder, so strain files could not be found. CannabisPlus now works around it using Community Framework. Keep CF updated.
- If your -profiles folder is outside the server folder (some hosts do this), the 8 built-in strains still load with your settings, but extra custom strain files won't load. A WARNING about this appears in the script log (and CF's own error about it is avoided). To load custom strains, put the -profiles folder inside the server folder, for example -profiles=profiles or -profiles=C:\DayZServer\profiles.
- This is temporary until Bohemia fixes DZEXP-134. Servers on DayZ 1.29 are not affected.

No items removed. No config file changes required. Servers on DayZ 1.30 that use custom strains may need to change their -profiles launch parameter (see above).
