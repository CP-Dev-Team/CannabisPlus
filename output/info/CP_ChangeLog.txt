Experimental (DayZ 1.30 test build, Workshop experimental branch)
Update all four agriculture mods together: AgricultureCore, GardeningPlus, DrugsPLUS and CannabisPlus.

Mod Changes
- Unpacking joint packs now uses AgricultureCore's shared unpack action. Requires the latest AgricultureCore.
- Unpacking DrugsPLUS and vanilla cigarette packs is now handled by DrugsPLUS instead of CannabisPlus.
- Unpacked joints now drop onto the ground surface instead of at the player's exact position.
- Raw and dried cannabis plants can be put in AgricultureCore's new compost bin.
- The fertilizing-speed settings code moved to AgricultureCore. The settings themselves were already in AgricultureCore.json, so nothing changes for you.

Fixes
- Smoking too much now makes players vomit on multiplayer servers. Before, the server never counted joint puffs, so it only worked in singleplayer.
- The stoned screen effect now reliably starts after JointCyclesToActivateEffect puffs on multiplayer servers. Before, the count could be reset by the server mid-smoke.
- The stoned screen effect now combines with DrugsPLUS effects instead of being cleared when one of them wears off. Needs the latest AgricultureCore.
- Drying post: raw plants with no yield set (for example spawned with admin tools or bought from traders) now dry into the strain's CropCount instead of 1 bud.
- Drying post: no longer creates an extra empty bud when the total divides evenly into stacks.
- Drying post: buds that don't fit in the post now drop on the ground next to it instead of being lost.
- Drying post: a raw plant it can't dry (no settings loaded for its strain and no yield, or no bud item for it) now
  stays on the post instead of being deleted without buds. A WARNING in the script log names the plant.
- Drying post: players can no longer try to take plants off while it's drying, and the rope can't be pulled off a post that has items on it.
- Crafting names and the "Rip open" action are now translated (they were always English): Fill Bag, Wrap Brick,
  Roll Joint, Create a pack of joints, Put joint into pack, Make Wooden Drying Post, Make CBD Crude Oil,
  Make Cannabis Workbench Kit, Tear apart Workbench.

Config Changes
- Your settings in CannabisPlus.json and your strain files are now kept when the mod updates. Previously an update moved every strain file into ConfigBackup and replaced them with defaults, so custom strains disappeared from the strains folder. New settings are added with their default values and settings that no longer exist are removed. A copy of your old files is still saved in profiles/CannabisPlus/ConfigBackup/v<old version>.
- If CannabisPlus.json or a strain file has a mistake in it (for example a missing comma), the mod now logs an error in the script log and uses default settings for that file until it's fixed, instead of silently using zeros. Your file is not overwritten.

DayZ 1.30 Server Setup
- DayZ 1.30 has a bug (Bohemia ticket DZEXP-134) that stops mods listing files in the profiles folder the old way, so
  strain files were not found: no strains loaded, the drying post deleted raw plants without making buds, and strain
  settings were ignored. CannabisPlus now lists the folder the way 1.30 expects, so all strain files load again,
  including custom strains, wherever your -profiles folder is. No launch parameter changes needed. (Thanks to the
  server owner who reported this and found the fix.)
- Strain files are backed up again when the mod updates (the backup also missed them on 1.30).
- Servers on DayZ 1.29 are not affected.

No items removed. No config file changes required.
